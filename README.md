# 全球市场情绪仪表盘

GreedyFear 中文版。把恐惧与贪婪收成 0–100 的分数，一眼看懂全球市场正在怕什么、贪什么。

约每 30 秒自动核对一次。休市时保留最近成交价。

## 页面上有什么

- **全球市场情绪**：股指、商品、汇率等市场脉搏
- **大型科技公司**：主要科技股各自的情绪位置
- **加密与中国资产**：比特币、以太坊，以及和中国市场相关的指标

分数越低越恐惧，越高越贪婪。

## 分数怎么算

- 波动率按固定区间**反向**换算：股市、黄金与沪深 300 用 10–40，恒指波幅用 15–45，原油用 25–80
- 个股、比特币与以太坊看它们在 **52 周区间**里的位置
- 美元指数相反：越靠近一年高点，越偏恐惧

某几项暂时拉不到时，其余指标仍会更新，页面会标明有多少项不可用。
